# Previsualizaciones móviles

Capturas generadas con Expo Web en un viewport de 390 × 844 px y tema oscuro.

- `01-login.png`: acceso a la cuenta.
- `02-role-selection.png`: selección entre cliente y proveedor.
- `03-register-client.png`: formulario de creación de cuenta de cliente.
- `04-catalog.png`: catálogo móvil para explorar y agregar productos al RFQ.
- `05-rfq-selection.png`: solicitud RFQ con productos, cantidades y prioridad.
- `06-payment.png`: selección de método de pago y registro de comprobante.
- `07-shipping-tracking.png`: seguimiento de envío, dirección, progreso y reclamos.

Las capturas se generaron localmente contra la aplicación Expo. Las vistas de compra, pago y envío usan datos de demostración interceptados únicamente durante la captura; no incluyen datos reales ni sesiones autenticadas.
